# ScientificApex agent entry point

Read the root README, AGENTS.md and LICENSE_SCOPE.md. The clone root is the
workspace; there is no inherited researcher profile or active scientific study.
Use the installed CLI independently, or connect an agent of your choice that
can operate local files and terminal commands. GEMINI.md is an optional adapter.

Install with instalar.ps1 on Windows, or bash instalar.sh on Unix-like systems.
See docs/portugues/guia_de_uso.md and docs/ingles/guia_de_uso.md for scientific
project contracts, protocol gates, optional runtimes and verification limits.

Query the operational graph before broad navigation. It is a source map, not
scientific evidence. Never turn the root into a research corpus or upload human
data as an installation step. Current checks and known limits belong in the
validation report; availability of a plugin or model must be checked separately.
