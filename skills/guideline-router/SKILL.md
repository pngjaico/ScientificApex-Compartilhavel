# Guideline Router

Use this skill before drafting methods, abstracts, tables, flow diagrams, or submission checklists.

## Default Routing
- Systematic review or meta-analysis: PRISMA 2020, plus extension when applicable.
- Randomized trial: CONSORT 2025.
- Observational study: EQUATOR-indexed design-specific guideline, commonly STROBE.
- Diagnostic accuracy: route to the current EQUATOR-indexed diagnostic guideline before drafting.

## Gate
- Record the chosen guideline in `standards.yaml`.
- Add a checklist artifact before Review Trinity.
- Do not claim compliance from narrative prose alone.
