# Retraction Integrity Checker

Use this skill before treating a citation as safe evidence.

## Gate
- Check DOI/PMID identifiers when declared.
- Use Crossref/Crossmark retraction metadata when available, with the caveat that coverage is incomplete.
- Record integrity checks in the retrieval or evidence manifest.
- Block a claim if its only support is retracted or has unresolved expression-of-concern status.

## Caveats
- Absence of a retraction flag is not proof of integrity.
- Corrections and errata require manual interpretation before claim promotion.
