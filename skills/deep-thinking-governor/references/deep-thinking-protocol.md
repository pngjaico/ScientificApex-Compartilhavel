# Deep Thinking Protocol

Use this as a compact checklist, not as a long report template.

## Decision Frame

- Decision: what must be chosen now?
- Consequence: what breaks if the choice is wrong?
- Evidence class: direct data, literature, expert assumption, benchmark, or untested inference.
- Reversibility: reversible, costly to reverse, or irreversible.

## Reasoning Audit

1. List plausible options, including doing nothing.
2. Name the strongest reason each option could be right.
3. Name the strongest reason each option could be wrong.
4. Identify missing evidence that would flip the decision.
5. Check whether the preferred option depends on hidden assumptions.
6. Define a verification step before committing to a strong claim.

## Scientific Red Flags

- Association treated as causation.
- Database output treated as proof.
- Small exploratory result treated as definitive.
- Search strategy or citation set shaped after seeing the answer.
- Benchmark/audit pass mistaken for real manuscript quality.
- "Perfect" claimed without residual-risk notes.
