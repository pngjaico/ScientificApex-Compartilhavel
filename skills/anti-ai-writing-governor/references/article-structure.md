# Article Structure Reference

Use this reference when the task is manuscript structure, abstract flow, article logic, journal readiness, or section-level rewriting.

## Core Structure

- Use IMRAD for original research: Introduction, Methods, Results, and Discussion.
- End the Introduction with the objective or research question. Do not bury the objective in background.
- Methods must be operational: design, setting, source, period, population, eligibility, variables, outcomes, statistics, software, ethics, and registration when applicable.
- Results must present the data before interpretation. Use tables for dense numbers; use text for direction, magnitude, and the primary answer.
- Discussion should open with the main finding, then compare with prior literature, explain plausible mechanisms carefully, state strengths and limitations, and close with a proportional implication.
- Conclusion should answer the objective, not advertise the paper.

## Study-Type Routing

- Systematic review/meta-analysis: PRISMA, PRISMA-NMA when network meta-analysis is involved, search strategy, eligibility, screening, extraction, risk of bias, synthesis, heterogeneity, certainty.
- Clinical trial: CONSORT, trial registration, randomization, allocation concealment, blinding, outcomes, harms, protocol deviations.
- Observational study: STROBE, data source, sampling, exposure/outcome definitions, confounding, missing data, sensitivity analyses.
- Diagnostic study: STARD, index test, reference standard, thresholds, flow, accuracy estimates, QUADAS-2 when reviewing evidence.
- Prediction model: TRIPOD, predictors, outcome, sample size, missing data, validation, calibration, discrimination.

## Anti-Template Structure Checks

- A structured abstract must contain the actual objective, design/source, population, main numeric results, and conclusion bounded by evidence.
- A paragraph should have one job. If it lists background, method, result, and implication in one sentence, split it.
- Generic first sentences such as "X is an important global problem" are weak unless followed immediately by the precise gap.
- Avoid ending every section with a universal promise. Name the concrete next step or limitation.
