# Security / Segurança

Do not post credentials, patient data, restricted full texts, private protocols or
other sensitive information in issues or pull requests. Share minimal synthetic
reproductions. If GitHub private vulnerability reporting is available for this
repository, use it for security-sensitive findings; otherwise ask for a private
reporting channel without disclosing exploit details publicly.

Não publique credenciais, dados humanos ou material restrito em issues/PRs.
Prefira exemplos sintéticos mínimos. Use o canal privado de vulnerabilidades do
GitHub quando disponível; se não existir, peça um canal privado sem expor detalhes.

This project does not supply an authenticated browser profile, API keys or model
accounts. Audit optional integrations before enabling network calls, paid
services or data transfers. A local audit is not a security certification.

No guaranteed security response time is offered. Only the current main branch
is maintained; older snapshots may contain unresolved provenance records.
