# Optional Gemini and Antigravity adapter

This file is an optional entry point for Gemini-based agents, including Antigravity. It does not make this repository or workflow exclusive to those tools.

Read [AGENTS.md](AGENTS.md) for the shared repository and scientific-workflow instructions, then read the [Portuguese usage guide](docs/portugues/guia_de_uso.md) or [English usage guide](docs/ingles/guia_de_uso.md) as appropriate. Use the same local CLI, project contracts, evidence gates, privacy rules, and authorization requirements as any other agent. Do not assume a model, plugin, account entitlement, external database, or credential is available unless the user and runtime provide it.
